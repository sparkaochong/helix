## 0. 红线与授权边界

### 0.1 不可修改的业务定义（红线）

| # | 红线 | 形式化 | 代码锚点 |
|---|---|---|---|
| R1 | 因子计算时点 | 特征仅使用 `≤ D0 收盘` 已发布数据 | `search_window()`、`lead()` 使用范围 |
| R2 | 建仓时点 | D+1 开盘价买入 | `LabelConfig.entry_offset = 1` |
| R3 | 结算判定 | `high[D+2] ≥ open[D+1] × 1.08` → 正样本 | `LabelConfig.touch_offset = 2`, `target_ratio = 1.08` |
| R4 | 标签类型 | 二分类，正样本 = 事件触发 | `LabelSet.y ∈ {1.0, 0.0, NaN}` |

这四条**任何模块不得重新定义**。修改需走本文 §7.4 的变更协议。

### 0.2 一条必须当场说清的风险（红线的边界在哪里）

红线 R3 定义的是**标签**，不是**执行**。这两者在本项目已被实测证明不重合：

| | 净收益/笔 | CAGR | Sharpe | 最大回撤 |
|---|---|---|---|---|
| 按 R3 字面执行（触及即止盈） | **−0.469%** | −46.7% | −2.10 | −69.8% |
| 持到 D+2 收盘 | **+0.378%** | +51.6% | +1.35 | −32.8% |

*3 种子，样本外 431 交易日，0bp 滑点，命中率 35.27% / 基准 16.76% / lift 2.104。*

机制不在成本里，在收益分解里：选出的是高波动动量票，两侧都被放大（命中组持到收盘 +10.07%，未命中组 −4.58%）。+8% 止盈把唯一赚钱的一侧削平，亏的一侧任其奔跑。

**本文的处置**：R3 作为**排序目标**（标签）保持不变；**执行退出规则是独立参数**，默认 `exit_rule = close`（§6.4）。`target` 档保留但仅用于复现该负面结果。

> **风控备案（不掩盖）**：分类器 `P(触及8%)` 对 D+2 收盘收益的 IC 是 **−0.064**。也就是说排序目标与实际执行**反向**。这是本项目当前最大的方法论债务，记录于 §8 缺口台账 D1。在它关闭之前，任何基于 lift 的乐观结论都必须同时报出净收益。

### 0.3 统计推断与执行建模红线（v1.1 新增）

R1~R4 约束的是**业务定义**；以下五条约束的是**结论怎么下**。来源是 2026-08-13 的[基线终审](risk/baseline-final-review.md)：三项风控闭环交付后，基线的种子方差仍大于全部已量化偏差之和。

| # | 红线 | 触发处置 |
|---|---|---|
| **R5** | 任何性能结论必须以 **≥10 种子的置信区间**形式汇报，禁止只报点估计 | 结论段出现裸点估计 = P0 缺陷，结论作废 |
| **R6** | 任何因子显著性门槛必须按该次搜索的**实际评估表达式数**校准 | 未申报搜索强度的显著性声明一律无效 |
| **R7** | D1 关闭前，任何 lift / 命中率结论必须同时给出「净收益/笔 ± 种子标准差」与「对 D+2 收盘收益的 IC」 | 缺任一项则该结论不得引用 |
| **R8** | 冲击成本模型上线前，**禁止**用回测 CAGR 支撑任何仓位或资金规模决策 | 违反即视为越权决策 |
| **R9** | G3 增量消融的否决权不因方向切换而失效 | DL 合成模块产出的合成因子同样必须过 G3 |

**R5 的实测依据**（3 种子，样本外 431 交易日，t 分布 2 dof）：

| 指标 | 均值 ± σ | 95% CI | 显著为正 |
|---|---|---|---|
| CAGR（D+2 收盘退出） | 69.50% ± 45.28% | `[−42.98%, +181.98%]` | **否** |
| CAGR（真实递延退出） | 59.12% ± 40.61% | `[−41.77%, +160.01%]` | **否** |
| Sharpe（D+2 收盘退出） | 1.247 ± 0.490 | `[+0.030, +2.463]` | 勉强 |
| Sharpe（真实递延退出） | 1.120 ± 0.463 | `[−0.032, +2.271]` | **否** |

对照之下 D5 修正的量级是 CAGR −10.4pp、Sharpe −0.13，**比噪声半宽小一个数量级**。这就是 R5 存在的理由：报了标准差却按点估计下结论，等于没报。

## 1. 时点契约（全系统唯一对齐基准）

```
   D0 收盘              D+1 开盘             D+2 盘中           D+2 收盘
     │                    │                    │                  │
     │ 特征截止           │ 建仓 entry         │ high ≥ 1.08×entry │ 默认退出
     │ （只用 ≤D0）       │                    │ → 标签=1          │
     ▼                    ▼                    ▼                  ▼
  决策时点              成交时点             结算时点           执行退出
```

**行对齐规则**：任何 `(T, N)` 数组的第 `t` 行**永远**表示「在 `dates[t]` 收盘做出的决策」，而非「`dates[t]` 发生的事」。特征、标签、掩码、预测、回测记账全部按此对齐。

**唯一前视算子**：`lead()`，且仅允许出现在 `helix/labels/` 内。任何其他模块出现 `lead` 是 P0 缺陷。

## 2. 分层架构：模块边界与接口规范

### 2.1 层次划分

```
L0 数据层      helix/data/        原始落盘、面板构建、时点股票池、事件表槽位化
L1 标签层      helix/labels/      触及标签 + 可成交性过滤    ← lead() 唯一合法区
L2 特征层      helix/features/    基础字段 + 算子集（严格后视）
L3 搜索层      helix/gp/          类型化算子集、适应度、中性化、去重、导出
L4 合成层      helix/dl/          序列构造、GRU 合成、walk-forward 训练
L5 评估层      helix/eval/        日频 AUC/gini、IC/ICIR、precision@k、交易级回测
L6 切分层      helix/splits.py    带 embargo 的滚动切分（被 L3/L4/L5 共同依赖）
```

**依赖方向严格向下**：`L_i` 只能依赖 `L_j (j < i)` 与 `L6`。**L2 不得 import L1**——这是防止标签信息回流进特征最结构性的一道墙。

### 2.2 层间接口契约

| 层 | 入口签名 | 输出契约 | 不变量 |
|---|---|---|---|
| L0→L1 | `Panel.f64(name) -> (T,N) float64` | 行=交易日，列=股票 | 缺失为 NaN，不填 0 |
| L1 | `build_touch_label(panel, universe, cfg) -> LabelSet` | `y/valid/touch_tradable/entry_price/target_price/exit_price`，均 `(T,N)` 且按 D0 对齐 | 不可观测 → NaN，**永不为 0** |
| L0→L3(B) | `load_event_panel(...) -> EventPanel` | `(T, N_max)` 槽位网格 + `occupied` 掩码 | 槽位≠股票；时序算子硬断言拒绝 |
| L2 | `operators.*(x, window) -> (T,N)` | 严格后视 | `lead` 不入算子集 |
| L3 | `score_values(values, ctx, n_nodes) -> FactorScore` | `fitness/sign/fit_gini/fit_ir/sel_gini/coverage/n_nodes` | 非法返回 `INVALID = -1e9`，不返回 NaN 混入排序 |
| L3 | `residualize(values, basis, mask, min_residual_fraction=1e-6)` | 残差 `(T,N)`，已解释日 → NaN | 幅度守卫不可省略（§4.4） |
| L4 | `train_fold(...) -> (state_dict, factor_names, seq_len, span)` | 每折独立模型 | 打分前 `require_matching_factors` 校验 |
| L5 | `daily_gini(factor, y, mask, min_samples=50) -> (T,)` | 每日一个值，NaN=不可用日 | **按日算完再平均，永不跨日池化** |
| L5 | `daily_ic / summarize_ic(ic) -> {ic, icir, ann_icir, pos_ratio}` | 同上 | 同上 |
| L5 | `lift_at_k(score, y, mask, k) -> float` | 每日 `precision/base` 之比再平均 | 分母 `base > 0` 才计入 |
| L5 | `run_backtest(predictions, labels, candidate_mask, dates, label_cfg, cfg) -> BacktestResult` | `daily` DataFrame + `summary` dict | D0 排名后再做成交校验；成本乘法记账（§6.3） |
| L6 | `walk_forward(n_dates, cfg) -> list[Fold]` | `Fold(index, train, valid, test)` | 每条缝隙插入 `embargo_days` |
| L6 | `search_window(n_dates, cfg) -> slice(0, train_days)` | 因子发现的**唯一**可见区 | 违反即 P0 |

L4 的索引掩码分成两类：train/valid 用 `label_mask = labels.valid`，test 预测用
`prediction_mask = universe & D0因子覆盖率达标`。禁止用 `label_mask` 决定 OOS 预测是否
生成，否则预测矩阵的 NaN 会把未来标签有效性重新带回 D0 候选池。

### 2.3 两条数据通路的边界

| | A. 面板通路 | B. 事件表通路 |
|---|---|---|
| 输入 | Tushare 全市场 → `(T,N)` 股票面板 | 长表（每日入选股 × 数百特征）→ `(T,N_max)` 槽位 |
| 时序算子 | **有效** | **硬断言禁止**（`assert_no_time_series`） |
| 标签 | 自建（`build_touch_label`） | 源表自带 → 必须**核验**不得假设（§5.4） |
| 产物 | 预测 `predictions.npz` | 因子列 + `apply_factors.py` 独立脚本 |
| 实证状态 | **未跑过完整实证** | README 全部结论来自此通路 |

> 通路 A 的实证空白记入 §8 缺口台账 D4。当前不得用 A 通路的任何数字支撑上线决策。

## 3. 因子评价体系与入库门槛

### 3.1 四道门（G0→G3 顺序通过，任一不过即淘汰）

```
候选表达式 ──G0 计算合法性──► G1 统计显著性 ──G2 独立性──► G3 增量消融 ──► 入库
              (硬断言)           (对照校准)        (中性化+去重)   (唯一否决权)
```

### 3.2 G0 · 计算合法性（硬阈值，无例外）

| 指标 | 阈值 | 参数 | 依据 |
|---|---|---|---|
| 每日最少样本 | `≥ 50` | `gp.min_daily_samples` | 少于此的日 AUC 方差压倒均值 |
| 日覆盖率 | `≥ 0.40` | `gp.min_coverage` | 只在四成日子有值的因子无法构成策略 |
| 定义域占比 | `≥ 0.20` | `min_defined_fraction` | 低于此说明表达式在多数格点上退化 |
| 节点数 | `≤ 40`，深度 `≤ 8` | `gp.max_nodes / max_depth` | §4.3 复杂度惩罚 |

不达标返回 `INVALID = -1e9`（**不是 NaN**）——NaN 混进排序会被静默当成"未知"而非"淘汰"。

### 3.3 G1 · 统计显著性（阈值必须由对照校准，不得拍脑袋）

**核心纪律：阈值 = 安慰剂分布的 p99，不是约定俗成的数字。**

G1 复用 `scripts/make_cs_columns.py` 安慰剂臂的截面置换契约：标签只在同一交易日的
可观测样本内置换，同一组、同一日的置换对全部正式因子共用。每组置换逐日精确保留
正负样本数，不跨日移动标签。

**当前正式校准流程**：

```
1. 加载时即截断到正式训练窗 2022-01-04..2024-09-04（649 个交易日），加载后再次断言截止日
2. 只用 data/artifacts/argus/event_factors.json 的正式因子生成 1000 组日内标签置换指标
3. 取三项经验分布的 p99 作为 G1 阈值；真实因子三项都必须严格超过对应 p99
```

`argus_n40` 和 `argus_multi` 只按正式阈值做补充对照，永不参与经验分布、配置或正式
入库资格。完整分布、分位数和逐因子结果见[安慰剂 IC/Gini 校准报告](risk/placebo_ic_calibration.md)。

**在 argus_quant 上的当前生效值**（1000 组置换，分位数采用 `linear` 方法）：

| 指标 | 定义 | 入库阈值 | 状态 |
|---|---|---|---|
| IC mean（日频 Spearman 均值） | `abs(summarize_ic().ic)` | `> 0.02385873314708397`（p99） | 已校准生效 |
| ICIR | `abs(ic / std(ic, ddof=1))` | `> 0.3268323682458659`（p99） | 已校准生效 |
| 日频 gini | `abs(mean(daily_gini))` | `> 0.010281975864080419`（p99） | 已校准生效 |
| 年化 ICIR | `ICIR × √252` | 观察项，不设独立准入线 | 由 ICIR 派生 |
| 正 IC 占比 | `mean(ic > 0)` | 观察项，不设独立准入线 | 未纳入本次校准 |
| **sel 段符号一致** | `sel_gini > 0` | **必须**（硬） | 沿用现有方向检查 |
| AUC（= gini/2 + 0.5） | 日频 | 观察项，不设独立准入线 | 与 gini 等价展示 |

**联合准入规则**：IC mean、ICIR、gini 必须**同时严格大于**各自 p99；等于阈值不算
通过。p95 和 p99.9 只用于显著性分级，不改变正式 p99 准入线。通过 G1 仅表示显著超越
训练窗内随机水平，**不能推翻 G3；G3 仍是唯一具有否决权的门。**

> **阈值适用边界**：当前 canonical `daily_ic` 对二元标签采用 ordinal rank，因此零分布
> 会随事件槽位布局、有效样本/缺失结构以及参与校准的正式因子族变化。这些阈值不是可跨
> 数据集复用的理论常数；数据、槽位布局、缺失结构或正式因子库变化时，必须在对应训练窗
> 内重新校准，严禁借用样本外数据更新门槛。

### 3.4 G1 补充 · 交易侧指标（与 IC 并列，不可互相替代）

| 指标 | 定义 | 阈值 | 备注 |
|---|---|---|---|
| 多头提升度 lift@k | `mean(precision@k / base_rate)` | `≥ 1.30` | k 取实际持仓数（4） |
| 止盈胜率 | top-k 命中率 | `≥ 1.3 × 基准率` | 与 lift 同源，单列出来因为它是业务语言 |
| **盈亏比** | `mean(命中组收益) / |mean(未命中组收益)|` | `≥ 1.50` | **新增强制项**，见下 |
| 净收益/笔 | 扣费后（§6.3） | `> 0` | **一票否决** |

> **为什么必须新增盈亏比**：本项目的核心教训是 lift 2.10 与 CAGR −47% 可以同时成立。`lift 度量排序，不度量赔率`。只看 IC/lift 的评价体系会把一个把赢家封顶、放任输家的策略判为优秀。盈亏比与净收益/笔是把赔率强行拉进评价体系的两个钩子。当前实测：命中组 +10.07% / 未命中组 −4.58% → 盈亏比 2.20（持到收盘口径）。

### 3.5 G2 · 独立性

| 规则 | 阈值 | 实现 |
|---|---|---|
| 与已保留因子的截面秩相关 | `|corr| ≤ 0.70` | `pairwise_max_abs_corr`，贪心去重 |
| 名人堂容量 | 60 | `gp.hall_of_fame` |
| 最终保留数 | 24 | `gp.n_keep` |
| 中性化基 | IC 最强 N 个源列 + 已发现因子 | `--neutralize-base N --rounds K` |

去重顺序：名人堂 → 过 sel 段符号检验 → 按 `sel_gini` 降序 → 贪心去重 → 取前 24。

> 喂 24 个同一想法的副本，效果不如喂 8 个真正不同的。

### 3.6 G3 · 增量消融（**唯一具有否决权的门**）

**这是本规范最重要的一条。G0~G2 全过但 G3 不过的因子一律不入库。**

依据是一个真实负面结果：17 个因子与 12 个因子两组，G0~G2 全部通过，G3 消融显示增量**全部落在种子噪声内**：

| 因子集 | IC | top20 命中率 | lift |
|---|---|---|---|
| 基线（459 列） | +0.09936±0.00119 | 35.51%±0.63 | 2.106±0.038 |
| + 17 个因子 | +0.09905±0.00069 | 35.51%±0.73 | 2.106±0.043 |
| + 12 个因子 | +0.10007±0.00097 | 35.46%±0.23 | 2.103±0.014 |

**G3 执行规格（不可简化）**：

| 要素 | 规定 |
|---|---|
| 工具 | `scripts/ablate_factors.py` |
| 控制变量 | 相同的行、切分、超参、**种子集合**；唯一差异是特征集加不加因子列 |
| 种子数 | **≥ 3**（单种子结果一律不采信） |
| 判定阈值 | 增量 `> 2σ_seed` |
| 当前 σ_seed | 命中率 0.63pp、lift 0.038、IC 0.00119 |
| **当前生效门槛** | **命中率 +1.30pp** 且 **lift +0.076** |

> **单种子的危险性有实测**：首次单种子消融显示命中率 **−1.0pp**，三种子下实际是 **+0.004pp**。符号都是反的。

**G3 的两个已验证否决案例**（作为判例保留）：

| 案例 | 表面证据 | G3 结果 | 结论 |
|---|---|---|---|
| GP 因子（17/12 组） | 残差 IC 显著、去重后独立 | 全落噪声内 | GP 因子是已有列的确定性函数，不引入新信息 |
| `strategy_name` one-hot | 六个取值基准命中率差 **2.6 倍**（21.71% vs 8.24%） | +0.14pp（门槛 1.30pp） | 模型早已从别的列推出该分层 |

**统一结论**：确定性的重新编码拿不到增量，不管它是 GP 表达式还是分类变量 one-hot。要有增量必须引入**表外新信息**。

### 3.7 什么情况下才值得继续挖因子

G3 连续否决后，继续投入搜索预算需满足以下之一：

1. 引入**新的原始信息**（盘口、资讯、其他频率），而非重组已有列；
2. 下游模型受容量限制（线性/小模型），人工结构确实有用；
3. 数据集**缺少截面算子构造的列**（本项目命中此条：459 列里仅 39 个 rank 型、18 个有对应兄弟列，**402 列没有任何截面版本**，而每日池子在 174~2656 之间摆动）；
4. 更换预测目标（当前目标可能已被现有特征吃透）。

## 4. 过拟合防控

### 4.1 样本三段式隔离

```
[──── train 750 ────][emb 5][── valid 120 ──][emb 5][── test 120 ──]
                                                          step 120 → 下一折
```

| 段 | 用途 | 禁止用途 |
|---|---|---|
| train | 参数拟合 | 早停判据、任何选择 |
| valid | 早停、超参选择 | 梯度更新、结论汇报 |
| test | **仅出结论** | 任何形式的选择与调参 |

**embargo 强制校验**：`split.embargo_days ≥ label.touch_offset + 1`，在 `Config.load` 中不满足直接 `ValueError`（`config.py:145`）。当前 `5 ≥ 3`。

> 理由：D0 决策的样本在 D+2 才结算，紧邻切分会让训练集尾部泄漏到验证集头部。这是最常见、最难察觉的一类泄漏。

### 4.2 因子发现的窗口隔离（三重防自欺）

**① 搜索只看最老训练块。** `search_window()` 返回 `slice(0, train_days)`，其后所有数据留给 walk-forward。在全历史上挖因子再"验证"是自欺欺人。

**② fit / sel 双窗口。** 搜索块内部按 `fit_fraction = 0.8` 再切，中间隔 `embargo_days`：

```
[──── fit 段（驱动进化，最大化 |gini|）────][embargo][── sel 段（决定去留）──]
```

进化只看 fit 段；因子只有在 sel 段上**符号仍一致且为正**才保留。sel 段不足 20 行直接报错。

**③ 符号是自由参数。** gini `−0.2` 取负后与 `+0.2` 等价，故适应度用 `|gini|`，符号单独记于 `factors.json`。

### 4.3 复杂度惩罚

```
fitness = |mean(daily_gini(fit))| − complexity_penalty × n_nodes
```

`complexity_penalty = 0.0015`，`max_nodes = 40`，`max_depth = 8`。

标定含义：一个 40 节点的表达式在 fit 段承担 `0.06` 的相对适应度惩罚（≈ AUC +0.03），因此只有它相对更简单表达式的增量足以覆盖该成本时才划算。这是搜索排序项，**不与 G1 的全训练窗 gini p99 相加成入库硬门槛**；G1 仍独立要求 gini 严格 `> 0.010281975864080419`。

### 4.4 中性化与幅度守卫

默认适应度是**残差 IC**，不是原始 IC。每日基组（截距 + K 个基列截面秩）用批量 QR 正交化，秩亏方向置零。

**幅度守卫不可省略**（`min_residual_fraction = 1e-6`）：下游指标基于秩、尺度无关。一个被完全解释的因子残差只剩 `1e-16` 浮点噪声，**但那噪声仍保留原始排序**，会被当成信号打分。残差占比低于阈值的交易日直接判为已解释，返回 NaN。

**已知局限（必须写进任何汇报）**：投影在秩空间是线性的，**移除不了基列的单调非线性变换**。存活因子是**待验证候选，不是独立性的证明**。这正是 G3 不可跳过的原因。

### 4.5 训练侧防过拟合

| 决策 | 值 | 理由 |
|---|---|---|
| 损失 | `BCEWithLogitsLoss(pos_weight)` | — |
| `pos_weight` 上限 | **20** | 不封顶时 2% 正样本率给出权重 49，模型去追异常值 |
| 早停指标 | **日频 gini**，不是 pooled loss | loss 会因"学会哪些周整体好做"而下降；日频 gini 只有当天内排序变好才涨 |
| 早停耐心 | 5 | — |
| 梯度裁剪 | 5.0 | — |
| winsorize | ±4σ | 截面 z-score 后 |
| 模型选择 | GRU 而非 Transformer | 20 时间步、几十输入、正样本率个位数百分比。注意力没有可注意的，只会更快过拟合 |

## 5. 未来函数三重防控

三层互相独立，任何一层单独失效不会导致泄漏逃逸。

### 5.1 L1 数据层防控

| # | 机制 | 实现 | 违反后果 |
|---|---|---|---|
| D1 | 标签列前缀黑名单 | `LABEL_PREFIXES = ("label","target","y_","fwd_","future_")`，`assert_no_label_columns` 硬断言 | 源表同带 `label_d2_hit_3pct/5pct/8pct`，漏一个进特征集就能互相预测出 IC>0.6 的垃圾因子 |
| D2 | **前缀盲扫而非枚举** | 自动选列必须过前缀过滤 | 已发生过一次真实泄漏（枚举漏列），修复后 IC 回落到现实量级 |
| D3 | 时点股票池 | ST 判定用 `namechange` 历史还原**当日**股票名 | 用当前名过滤 = 用未来信息 |
| D4 | 缺失即 NaN | 不填 0 | 填 0 与"真实值恰好为 0"不可区分 |

### 5.2 L2 计算层防控

| # | 机制 | 实现 | 违反后果 |
|---|---|---|---|
| C1 | `lead()` 单点管制 | 仅允许出现在 `helix/labels/` | 唯一的前视算子 |
| C2 | 算子集严格后视 | 13 个 `ts_*` 全部后视；`lead` **故意不进算子集** | GP 永远碰不到未来数据 |
| C3 | 槽位面板时序算子硬断言 | `assert_no_time_series(pset)`，`FORBIDDEN` = 全部窗口算子 | 槽位 j 在不同日是不同公司，`ts_mean(x,20)` 会平均二十家不相干公司 |
| C4 | 截面标准化 population = `universe` | **不是** `labels.valid` | `labels.valid` 含 D+1 是否一字涨停、D+1/D+2 是否停牌——用它当 population，未来信息就会影响 D0 特征的均值和标准差；且会让最后两行全 NaN，正好是实盘打分需要数值的地方 |
| C5 | 层依赖方向 | L2 不得 import L1 | 结构性阻断标签回流 |

### 5.3 L3 回测层防控

| # | 机制 | 实现 | 违反后果 |
|---|---|---|---|
| B1 | embargo 强制校验 | `Config.load` 中 `ValueError` | §4.1 |
| B2 | 每折独立模型 | 只给该折 test 行打分，拼接各折 | 每个预测点都出自没见过该日期的模型 |
| B3 | 因子集一致性校验 | `require_matching_factors` | 因子库变了却用旧权重打分，是静默错到底那类 bug |
| B4 | 实盘打分候选集 = D0 股票池 | 不是 `labels.valid` | 最新一根 K 线特征在 D0 收盘已完整，标签必然未定义——那正是要预测的东西 |
| B5 | 成本按交易日取值 | 印花税 2023-08-28 减半，`STAMP_CUT_DATE` | 全程用一个数 = 用未来税率算历史 |

### 5.4 核验纪律：零不构成证据

**外部数据的保证只能核验，不能假设。** 事件表通路用源表自带标签，故本项目建立了强制核验协议：

| 脚本 | 回答什么 | 关键设计 |
|---|---|---|
| `check_suspension.py` | 停牌是被剔了还是被静默填 0 | **正对照**：同一查表逻辑在不该被过滤的偏移量上必须有命中，全零直接 `SystemExit` |
| `check_fillability.py` / `fill_impact.py` | 源表有没有剔除买不进的样本，影响多大 | 两道独立校验反推涨停价 |
| `make_cs_columns.py` | 402 列截面版本有没有增量 | **安慰剂臂**：日内行置换，保持边际分布/列间相关/列数，只打断对齐 |
| `ablate_factors.py` | 加了因子列下游真的变好了吗 | 多种子 |
| `window_stats.py` | 短窗对照表的数字在长曲线上是什么分位 | 同长度窗口比较 |

**协议**：任何"我们没有泄漏"的结论，必须附带一个**在有泄漏时会失败的对照**。没有对照验证的零不构成证据。

**已核验事实（argus_quant）**：

- 停牌：D+1/D+2 命中 **0 行**，而 D−10/D−1/D+0/D+3/D+10 共命中 7,546 行 → 确实剔了，不是填 0。
- 独立重建：79 个交易日全市场行情（399,625 根 K 线）比对 32,146 行，标签与原始价重算 **100.0000%** 一致。
- 可成交性：**确实没剔**。2,933 行（0.475%）D+1 开盘即涨停，标签 NaN 比例 0.00%，这批命中率 37.47%（可成交样本的 2.5 倍）。
  - 影响量级：fill-aware 口径命中率 35.51% → **35.27%**（−0.24pp），在种子噪声 ±0.64pp 内；lift 2.106 → 2.104 几乎不动（分子分母同向移动）。
  - **诚实数字是 35.3% / lift 2.10**，不是 35.5% / 2.106。

## 6. 回测引擎规格

### 6.1 成交价格

| 环节 | 价格 | 口径 |
|---|---|---|
| 建仓 | D+1 开盘价 | 后复权 `open_hfq` |
| 退出（默认） | D+2 收盘价 | 后复权 `close_hfq` |
| 退出（`target` 档） | `entry × 1.08` | 仅用于复现负面结果 |
| 涨跌停比较 | **原始价** | 涨停价按原始价报价，必须原始价比 |

> **复权纪律**：收益比值一律用后复权价；原始价**只用于**与涨跌停价比较。混用会在除权日凭空跌掉一笔分红，把命中算没。

### 6.2 剔除规则（三条，全部返回未定义而非 0）

| # | 规则 | 处置 |
|---|---|---|
| E1 | D+1 开盘价 `≥` 当日涨停价 − `limit_price_eps(0.001)` | **剔除**（一字涨停买不进） |
| E2 | D+1 或 D+2 停牌 | 标签未定义（结果不可观测） |
| E3 | 不在 D0 股票池 | 标签未定义 |

**股票池过滤**：排除 ST、次新（上市 < 120 日）、北交所、成交额 < 2000 万、收盘价不在 `[2, 1000]`。

### 6.3 交易成本（A 股法定口径，乘法记账）

```
net = (1 + gross) × (1 − sell_rate) / (1 + buy_rate) − 1
```

| 项目 | 费率 | 方向 | 备注 |
|---|---|---|---|
| 佣金 | 2.5bp | 双边 | `commission_bps` |
| 过户费 | 0.1bp | 双边 | `transfer_bps` |
| 印花税 | **5bp** | **仅卖出** | 2023-08-28 起；此前 **10bp**，按交易日取值 |
| 滑点 | 10bp | 单边 | `slippage_bps`，叠加在法定费率之上 |

**两条不可简化**：

1. **成本不是从毛收益里减一个常数**——按名义本金逐边计。
2. **印花税按交易日取值**，不是全程一个数。面板数据从 2018 年起，横跨 2023-08-28 减半。盈亏平衡点在**单边 19bp**，5bp 的税率误差就是四分之一的余量。

`BacktestConfig` 设 `extra="forbid"`：遗留的 `cost_bps` 键直接报错，而非被 pydantic 静默忽略后悄悄改用新默认值。

### 6.4 持仓与卖出规则

| 参数 | 值 | 依据 |
|---|---|---|
| 持仓数 `top_k` | **4** | 见下表 |
| 候选深度 `signal_k` | **5** | 留出替补深度，涨停买不进要能顺延 |
| 退出规则 | `close`（全部持到 D+2 收盘） | §0.2 |
| 资金拆分 `overlap` | `touch_offset − entry_offset + 1 = 2` | 每天开新仓时上一批未平 |

**持仓规模的实测依据**（3 种子，431 交易日，持到收盘，单边 10bp）：

| 持仓 | Sharpe | 最大回撤 | 终值 | 日胜率 |
|---|---|---|---|---|
| 1 | +0.13±0.28 | −72.8% | 0.70 | 45.5% |
| 3 | +1.40±0.19 | −45.4% | 3.04 | 50.2% |
| **4** | **+1.39±0.02** | −41.1% | 2.76 | 51.0% |
| 8 | +1.32±0.23 | −37.1% | 2.31 | 53.5% |
| 20 | +0.67±0.13 | −34.0% | 1.35 | 51.6% |

三条同时成立：

1. **持仓 1 是灾难**且有机制——`P(触及8%)` 对 D+2 收盘收益的 IC 是 −0.064，只买第一名等于对负相关那一端全额下注。
2. **回撤随持仓数单调变浅**（−72.8% → −34.0%），但**日胜率几乎不动**。分散改的是方差，不是出手的对错率。
3. 取 4 而非 3：3 的 Sharpe 高 0.01 而种子标准差是它的 9 倍（±0.19 vs ±0.02）。

> **必须声明的保留**：hold 是在测试集上看着结果挑的。「1 很差」「≥3 好过 ≤2」「票越多回撤越浅」是有机制的结构性结论；**峰值恰好落在 3~4 这件事本身是挑出来的**，不构成样本外保证。

### 6.5 汇报口径（强制）

任何回测汇报必须**同时**给出以下五项，缺一不予受理：

```
lift / 命中率 vs 基准率 / 净收益每笔 / Sharpe / 最大回撤 + 滑点敏感性
```

> **lift 是第一个该看的数字，但不是最后一个。** lift 2.10 对应的净收益可以是 −0.47%/笔。

## 7. 终审协议（架构师/风控负责人职责）

### 7.1 代码终审检查表（每次因子或模型交付前逐条执行）

**A. 泄漏排查**

- [ ] `grep -rn "lead(" helix/ --include=*.py` → 命中只出现在 `helix/labels/`
- [ ] `assert_no_label_columns` 在所有特征选择路径上被调用

- [ ] OOS 预测索引用 D0 `prediction_mask`，不是 `labels.valid`
- [ ] `Config.load` 的 embargo 校验未被绕过
- [ ] 任何"缺失"处置是 NaN 而非 0
- [ ] 特征计算链路上没有任何 `≥ D+1` 的数据引用

**B. 隐性泄漏（更难发现的一类）**

- [ ] 候选集是否用到了 D+2 才知道的信息（必须先按 D0 `universe` 固定名单）
- [ ] 归一化/分箱的统计量是否在全样本上计算（应仅用训练段）
- [ ] 缺失值填充是否用了全样本均值
- [ ] 超参是否在 test 段上选过
- [ ] 特征列名是否暗含未来信息（前缀盲扫覆盖 5 类前缀）

**C. 结论有效性**

- [ ] 多种子（≥3）且报出标准差
- [ ] 有对照臂（安慰剂/正对照），零结果有对照支撑
- [ ] 指标按日算完再平均，未跨日池化
- [ ] G3 消融已执行且超 2σ

### 7.2 实盘泛化价值判定

一个因子/模型被判定为**具备实盘泛化价值**，需同时满足：

1. G0~G3 全过，G3 增量超 2σ_seed；
2. 净收益/笔 > 0 且在**单边 20bp 滑点**下仍 > 0（当前盈亏平衡点 19bp，余量极窄）；
3. 结论在 ≥3 种子上**符号一致**；
4. 泄漏检查表 A/B 全绿；
5. 未依赖任何在 §8 台账中标记为「偏乐观」的未建模项。

**任一不满足 → 判定为「研究结论」，不得进入实盘配置。**

### 7.3 严重度分级与处置

| 级别 | 定义 | 处置 |
|---|---|---|
| **P0** | 数据泄漏、前视函数、标签污染 | **停工**。当场修复 + 当场提交，不得带入下一阶段 |
| **P1** | 结论有效性缺陷（单种子、无对照、跨日池化） | 结论作废，重跑后方可汇报 |
| **P2** | 记账口径错误（成本、复权、剔除规则） | 当前 Phase 内关闭 |
| **P3** | 可维护性 | 记录，排期 |

### 7.4 红线变更协议

修改 §0.1 任一红线需：书面说明动机 → 新旧口径**并行**跑一遍完整 G0~G3 → 两套结果同时汇报 → 用户明确批准 → 原子提交并更新本文版本号。

阶段结束时逐条可查，任一未达成则不得宣布阶段完成：

| # | 验收项 | 判定方式 |
|---|---|---|

## 9. 全局不变量（任何改动不得破坏）

1. 第 `t` 行 = 在 `dates[t]` 收盘做的决策。
2. `lead()` 只出现在 `helix/labels/`。
3. 标签不可观测时是 NaN，永远不是 0。
4. 后复权价算收益比值；原始价只用于与涨跌停价比较。
5. GP 搜索只看 `search_window()`。
6. 所有指标按日算完再平均，不跨日池化。
7. 截面标准化的 population 是 `universe`，不是 `labels.valid`。
8. D0 候选排名只用 `universe`；未来可交易性只能在固定名单后的成交校验中使用。
9. OOS 预测的生成范围由 D0 `prediction_mask` 决定，不由 `labels.valid` 决定。
10. 槽位面板上时序算子是硬断言拒绝，不是约定。
11. 特征集里不能出现 `label*` 前缀列，硬断言。
12. `embargo_days ≥ touch_offset + 1`，配置加载时校验。
13. **单种子结果不构成证据**：消融/对照类实验 ≥3 种子且报标准差；**性能结论（CAGR/Sharpe/回撤）≥10 种子且报 95% 置信区间**（§0.3 R5）。
14. **没有对照验证的零不构成证据**。
15. **G3 增量消融是唯一具有否决权的门**，G0~G2 全过不等于入库。
16. **lift 度量排序，不度量赔率**；任何回测汇报必须同时给出净收益/笔。

## 10. 一个必要的预期管理

这套框架解决的是**方法论正确性**问题——它保证测出来的数字是真的。**它不保证数字好看。**

本项目当前的实证状态是：排序能力真实存在且已被多重核验（lift 2.10，经停牌、可成交性、独立数据源三重验证），但

- GP 因子对下游模型**零增量**（两次独立验证）；
- 按标签字面执行是**负期望**；
- D+2 跌停递延已完成量化并提供可选修正（D5）：开启真实退出后 CAGR 回落
  **10.4pp**、夏普回落 **0.13**；默认关闭时仍保留这部分已量化的乐观偏差；
- 滑点余量只有**单边 19bp**；
- **3 种子下 CAGR 与修正后 Sharpe 的 95% 置信区间均跨越 0**（§0.3 R5 表）——
  已量化的偏差全部比这个噪声小一个数量级。当前状态是「排序能力已验证、
  盈利能力未验证」，§7.5 的降级条款处于已触发状态。

把这些写在规范里，不是为了泄气，是因为**一个会汇报坏消息的评价体系，才有资格让人相信它汇报的好消息**。

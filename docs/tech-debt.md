# 技术债台账

## TD-001 · Placebo 校准的 `min_samples` 未绑定配置

- **优先级**：Low
- **状态**：Open
- **记录日期**：2026-08-13
- **范围**：`scripts/calibrate_placebo.py`

**风险**：安慰剂校准命令的 `min_samples` 目前使用脚本默认值 `50`，未从
`gp.min_daily_samples` 读取。若两处参数日后分叉，校准分布与因子主流程可能使用不同的
每日最少样本门槛，导致 G1 阈值与实际评分口径不一致。

**修复建议**：让校准命令默认从 `Config.gp.min_daily_samples` 取值，同时保留显式
CLI 参数作为可审计覆盖；将最终生效值写入分布元数据和校准报告，并新增测试确保
默认配置、CLI 覆盖与报告记录三者一致。

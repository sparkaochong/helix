## 2. 未覆盖的核心风控漏洞

### P0-A · 结论的种子方差远大于所有已量化偏差

数据源：`docs/risk/d2_limit_down_bias.md`，3 个种子，样本外 431 交易日。

| 指标 | 均值 ± σ (n=3) | 逐种子 | 95% CI（t 分布，2 dof） | 是否显著为正 |
|---|---|---|---|---|
| CAGR（开关关闭） | 69.50% ± 45.28% | 31.31 / 57.67 / 119.52% | `[−42.98%, +181.98%]` | **否** |
| CAGR（开关开启） | 59.12% ± 40.61% | 25.53 / 47.58 / 104.26% | `[−41.77%, +160.01%]` | **否** |
| Sharpe（开关关闭） | 1.247 ± 0.490 | 0.801 / 1.168 / 1.771 | `[+0.030, +2.463]` | 勉强 |
| Sharpe（开关开启） | 1.120 ± 0.463 | 0.707 / 1.030 / 1.621 | `[−0.032, +2.271]` | **否** |

**两项 CAGR 的置信区间均包含 0 与负值；修正后的 Sharpe 置信区间已跨过 0。**

对照之下，D5 跌停递延修正的量级是 CAGR −10.4pp、Sharpe −0.13——**比种子噪声的半宽小一个数量级**。即：项目精确量化了一个远小于噪声的偏差，而噪声本身未被治理。

这不违反不变量 #13 的字面（标准差已汇报），但违反其精神：标准差报了，结论仍按点估计下。

**判断的方差来源**：`top_k = 4`。431 个交易日仅 1694 笔交易，每日 4 只高波动动量票，组合层面无分散度。这不是"多跑几个种子"能消除的，它决定了本策略的信息比率上限。D7（无行业中性化）很可能是同一方差的另一个来源——Top-4 + 高波动动量选股极易反复集中于同一板块主题。

### P0-B · 安慰剂阈值的多重检验修正与实际搜索强度失配

代码锚点：`helix/eval/placebo.py:252-258`。

```python
final_metrics = np.column_stack((
    np.max(np.abs(ic_means), axis=1),   # max over K 个正式因子
    ...
))
```

零分布统计量是 **max over K**，而 `docs/risk/placebo_ic_calibration.md` 记录 `Formal factors: 1`。因此当前 p99 线的物理含义是**单个随机因子的 99 分位**。

它要卡的对象是 GP 搜索的产物：`GPConfig.population = 400`、`generations = 25`，单次运行评估 10⁴ 量级表达式。用 max-of-1 的分位数去卡「从 10⁴ 个表达式中挑出的最优者」，family-wise error 被放大三到四个数量级。

**当前不翻转任何结论**：`gp_000` 的 IC = 0.129，是 p99.9（0.0247）的 5 倍，任何修正下都通过。**但该阈值一旦用于卡 IC 落在 0.02~0.05 区间的边缘因子，会成批放行纯噪声**——而「提升 GP 挖掘效率」恰好会大量生产该区间的因子。

**次要缺陷（同源）**：`iter_cross_sectional_permutations` 逐日独立置换，零分布的日 IC 序列跨日 iid；真实因子的日 IC 存在 regime 序列相关。因此 **ICIR 的零分布偏窄，ICIR 门槛系统性偏松**。

### P0-C · D1 目标错配未决，是真正的结构性问题

已在 §0.2 备案：`P(触及8%)` 对 D+2 收盘收益的 IC = **−0.064**，而默认执行按 D+2 收盘退出。

含义：**赚钱的机制不是被优化的那个机制。** 当前正收益来自「选出高波动动量票」这一截面效应，而非分类器的排序方向。

推论——这是终审认为最严重的一条：**G1 安慰剂阈值与 G3 增量消融，全部是在对一个与最终 P&L 负相关的目标做统计检验。** 因子做得再显著，也是在优化错误目标。该条不关闭，任何提升搜索效率或增强拟合能力的投入，都只是在更高效地放大一个错误目标。

### P1-D · 冲击成本缺失，且滑点余量极薄

`BacktestConfig.slippage_bps = 10.0`（单边），而 `helix/eval/backtest.py` 模块 docstring 自算的盈亏平衡点是单边 **19bp**。余量仅 9bp。

Top-4 高波动票集中于 D+1 开盘建仓——集合竞价是冲击最坏的时点。10bp 对该类标的属乐观假设。**终审判断该项偏差量级大概率超过 D5 的 10.4pp**，应为下一个必须量化的偏差。

### P1-E · 递延持仓不占资金（新增台账 D13）

`helix/eval/backtest.py:455` 中 `overlap` 恒为 `touch_offset − entry_offset + 1 = 2`，而递延平仓的 `holding_days` 可以大于 2。`d2_limit_down_bias.md` 已声明「不另建动态资金占用模型」。

当前 0.53% 发生率下量级可忽略，但**跌停是聚集发生的**：流动性事件中发生率会高 1~2 个数量级，届时隐含资金占用超过 1，恰好出现在最不应加杠杆的时点。这是 regime-dependent 偏差，不能按均值发生率结案。

### P1-F · `matched_*` 口径会静默改变 headline（新增台账 D14）

`helix/eval/backtest.py:517,545-546`：`comparable` 要求 `baseline_net` 与 `realistic_net` 同时有限，否则两侧同时写 0；而 headline 的 `portfolio_return` 建在 `matched_realistic` 之上。

当前 `unresolved_at_end = 0`，两条曲线相同。一旦行情末端出现未平仓单，「真实退出曲线」会被静默替换为「与 baseline 可比子集」曲线。应额外输出一条不做 matching 的 realistic-only 曲线。

## 3. 收益与风险水平评估

**点估计好看，统计上尚不能宣称显著。**

- 修正后：CAGR 59.12%、Sharpe 1.120、最大回撤 −38.94%——但如 §2 P0-A，两项的置信区间均跨越 0。
- 前提条件：D1（目标错配）、D6（冲击成本）、D7（行业中性）三项全部未处理；样本外仅 431 交易日（不足 2 年，且为 2024-09 至 2026-07 单一 regime）。
- **排序能力是真的**：lift 2.104，经停牌、可成交性、独立数据源三重验证；正式因子 IC 超安慰剂 p99.9 达 5 倍。

准确表述：**排序能力已验证，赔率未验证。**

### 是否值得继续挖掘

**值得，但不是「继续挖因子」的价值。**

G3 已两次否决 GP 因子（17 组、12 组增量全落 2σ 种子噪声内），判例结论明确：确定性重编码拿不到增量。

§3.7 列出的四个「值得继续挖」的条件，项目仅命中第 3 条（缺截面算子构造的列）。而截面列**已经生成**：

```
data/artifacts/cs/argus_quant_working_cs.parquet   2.5 GB   2026-08-12
data/artifacts/cs/cs_real.json                              real 臂
data/artifacts/cs/cs_placebo.json                           安慰剂臂
```

**双臂齐备，但从未跑过 G3 消融。** 这是当前唯一一个数据已就绪、零新开发、能直接回答「这条路还有没有信息」的实验。

## 4. 下一阶段推进优先级

**A / B / C 均不列第一顺位。**

### 第一顺位 · 方向 D（新增）

**D-1 · 截面列 G3 消融。** 数据就绪，工具（`scripts/ablate_factors.py`）就绪，≥3 种子，判据沿用现行门槛（命中率 +1.30pp 且 lift +0.076）。

这是一个 **go / no-go 决策点**：若 402 列的截面版本在安慰剂臂对照下增量仍落 2σ 内，则 §3.7 的四个条件**全部落空**，正确决策是停止因子挖掘方向的一切投入，转向表外新信息（盘口、龙虎榜、资讯）。不得由 A/B/C 任一方向绕过此判定。

**D-2 · 关闭 D1 目标错配。** 三个候选目标做对照：

| 方案 | 目标定义 |
|---|---|
| (a) | D+2 收盘收益的截面 rank 回归 |
| (b) | 二分类，正样本改为「D+2 收盘收益 > 当日截面中位数」 |
| (c) | 保留 `P(触及8%)`，执行改为「触及即止盈 + 未触及持到 D+2 收盘」的混合规则 |

台账记载 (a) 在 hold≤4 时更差——需查清那是目标问题还是 `top_k=4` 的方差问题，当前二者混同。

### 第二顺位 · P0-A 方差治理 + P1-D 冲击成本

种子提至 ≥10；`top_k` 扫描 4 / 10 / 20 评估方差-收益权衡；接入按成交量约束的冲击成本模型（至少 `√(order/ADV)` 平方根律）并给出容量上限。

### 第三顺位 · 方向 C（收窄版）

C 是 A/B/C 中唯一现在就该做的，因为它是 P0-B 的载体。**范围必须收窄**为四件事：

1. 每个候选因子的独立置换检验；
2. BH-FDR 多重检验控制；
3. G3 消融自动触发；
4. 淘汰审计日志。

不做通用因子池管理系统。没有这套记账，A 产出因子越多，假阳性越多。

### 第四顺位 · 方向 A

**仅在 D-1 给出正结果后启动。** 搜索效率从来不是瓶颈——瓶颈是搜索空间内没有新信息（G3 判例已判定 GP 因子是已有列的确定性函数）。此时提升搜索效率，只会更快生产零增量因子，并按搜索强度成比例放大 P0-B 的多重检验问题。

### 冻结 · 方向 B

**现阶段开展深度学习非线性合成是错误的。** 依据是项目自身的 G3 判例：确定性重编码零增量。非线性合成同样是确定性重编码，只是函数类更大——在目标函数仍与 P&L 负相关（IC −0.064）的前提下，更强的拟合器只会更快、更彻底地拟合到错误目标上。

B 的解冻条件：D1 关闭 **且** 已引入表外新信息。

## 5. 终审结论一句话

三项闭环工作质量很高，但量化的是**已知的小偏差**。真正卡住项目的是三件事——目标函数与 P&L 反向（−0.064）、结论的种子方差跨越零点、唯一有增量假设的实验（截面列 G3）数据已备却未跑。**在这三件事解决前投入方向 A 或 B，是在给一个方向未定的系统加马力。**

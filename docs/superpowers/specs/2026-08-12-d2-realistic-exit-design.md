# D+2 跌停递延平仓设计

## 目标

在不改变 D0 选股、不补位和现有回测记账框架的前提下，为
`helix/eval/backtest.py` 增加可切换的真实可成交退出逻辑，量化“所有仓位都能按
D+2 收盘价平仓”这一假设的偏差。

默认配置继续使用现有 D+2 收盘口径。只有
`backtest.enable_realistic_exit: true` 时才读取 D+2 及后续交易日的退出行情。

## 不变项

- D0 候选池、预测排序和 Top-K 名单保持不变。
- D+1 未成交股票不向更深排名补位；对应槽位保持现金。
- 交易成本仍按逐笔名义金额乘法计算。
- 日组合收益仍归属于原 D0 篮子，并按现有固定
  `overlap = touch_offset - entry_offset + 1` 拆分资金。递延持仓天数只改变实际
  退出价和风险统计，不引入新的逐日资金账本或杠杆模型。
- `enable_realistic_exit=false` 的逐笔收益、日收益和汇总结果必须与改动前完全一致。

## 配置与接口

`BacktestConfig` 新增：

```python
enable_realistic_exit: bool = False
```

`run_backtest` 增加一个可选的、与预测矩阵同形状的行情面板参数。默认模式不要求该
参数；真实退出模式缺少行情面板时直接报错，不能回退到理想价格。

`BacktestResult` 增加逐笔 `trades` 表，同时保留现有 `daily` 和 `summary`。逐笔表至少
包含：D0 日期、股票代码、D+1 入场价、原 D+2 收盘价、实际退出日期和价格、成交时点
（`d2_close`、`open`、`close`）、是否 D+2 全天封死跌停、是否经历停牌、递延交易日数、
完整持仓交易日数、原始/修正毛收益和净收益、末端未平仓状态。

## 入场资格与标签职责

当前 `LabelSet.valid` 同时要求 D+1 和 D+2 可交易，因此不能区分“D+1 已买入、D+2
停牌”和“D+1 根本未成交”。真实退出模式必须拆开这两个概念：

- `entry_valid` 只使用 D0 股票池、D+1 交易状态、D+1 开盘价和 D+1 涨停不可买条件。
- `valid` 继续表示训练标签是否可观测，仍要求 D+2 可交易和 D+2 最高价有效。
- `entry_price` 对所有 `entry_valid` 样本保留，即使 D+2 停牌；训练用 `y` 仍只在
  `valid` 上有效。

默认回测继续使用原来的 `valid` 成交过滤，从而保持结果不变。真实退出模式使用
`entry_valid` 判断是否在 D+1 建仓，D+2 停牌的已建仓股票进入递延流程。

## 涨跌停数据契约

所有成交判断只读取正在判断的那个交易日的真实字段：原始 `open/high/close`、实际
`down_limit`、`is_trading`，以及成交计价所需的 `open_hfq/close_hfq`。

- 不根据股票代码、板块或固定 5%/10%/20%/30% 比例猜测跌停价。
- `Panel` 增加实际 `stk_limit` 是否存在的观测标记。真实退出判断只接受当日实际
  `down_limit`；缺失时该日不能判定为可卖，继续递延并记录缺失原因。
- 不同股票、ST 状态、上市板块和制度时期的差异均由当日实际 `down_limit` 自然体现。
- 价格比较使用 `LabelConfig.limit_price_eps`，相对误差设为零，避免浮点存储误差改变
  交易状态。

## 串行退出算法

对每个 D+1 已建仓仓位，按交易日严格串行执行：

1. 检查 D+2。
2. 若 D+2 停牌或没有有效行情，不能卖出，从下一交易日继续。
3. 若 D+2 的收盘价和最高价均在误差范围内等于当日实际跌停价，认定为全天封死
   跌停，从 D+3 继续。
4. 其他 D+2 可交易样本保持原假设，按 D+2 复权收盘价退出。
5. 对 D+3、D+4……逐日检查：
   - 停牌、行情缺失或缺少实际跌停价：继续递延；
   - 原始开盘价严格高于 `down_limit + eps`：按当日复权开盘价成交；
   - 否则，原始收盘价严格高于 `down_limit + eps`：按当日复权收盘价成交；
   - 否则继续递延。即使最高价显示盘中开板，只要开盘仍封跌停且收盘回封，也不
     假设盘中能够成交。
6. 扫描到行情面板末端仍没有可成交点时，标记 `unresolved_at_end=true`，不虚构
   退出价格。

递延天数定义为 `实际退出偏移 - touch_offset`，因此 D+3 退出为 1 天。完整持仓天数
沿用现有占用日定义：`实际退出偏移 - entry_offset + 1`，因此 D+1 入场、D+4 退出为
4 个交易日。

## 样本对齐与组合记账

原假设和修正结果共享同一份 D0 Top-K 名单和 D+1 入场判定。风险报告先生成逐笔交易
主表，再从同一主表派生两个收益列，禁止分别跑选股流程后再拼结果。

- 对存在有效 D+2 收盘价且真实退出已完成的仓位，原口径使用 D+2 收盘价，修正口径
  使用实际退出价。
- 面板末端仍未平仓的仓位在两组比较中都以零收益槽位保留，不进入已平仓逐笔收益
  均值，并在报告中单列数量、占比、代码、入场日和已持有天数。
- D+2 停牌导致原 D+2 收盘价不存在时，该仓位仍由真实模式递延和记录，但不能伪造
  原始收益。两组核心指标的 matched comparison 对该槽位均记为零，并另列“D+2
  停牌递延”结果，保证比较样本和每日分母完全一致。
- 每日分母始终是配置的 `top_k * overlap`，未成交、不可比较或末端未平仓槽位不把
  资金转给其他股票。

## 指标定义

两组核心策略指标全部从对齐后的日 `portfolio_return` 计算：

- CAGR：`final_equity ** (252 / n_days) - 1`。
- 最大回撤：累计净值相对历史峰值的最小跌幅。
- 日胜率：`portfolio_return > 0` 的交易日占全部回测日比例，零收益日不是胜日。
- 盈亏比：正收益日平均收益除以负收益日平均亏损绝对值；任一侧不存在时为 NaN。
- 最大连续亏损：`portfolio_return < 0` 的最长连续交易日数，零收益日中断序列。
- 夏普比率：日均收益除以样本标准差并乘 `sqrt(252)`，不另设无风险利率。

退出风险统计从逐笔主表计算：

- 跌停无法卖出样本占比：D+2 全天封死跌停仓位数 / D+1 实际建仓仓位数。
- 平均递延天数：已完成退出的 D+2 全天封死跌停仓位的平均递延交易日数。
- 平均亏损幅度：上述仓位按真实退出价计算的平均毛收益；同时报告相对 D+2 假设的
  平均收益变化。
- 停牌递延数量和面板末端未平仓数量单独列示，不混入跌停样本占比。

## 实际量化数据流

仓库当前没有标准面板流水线的 `data/cache/panel.npz` 和
`data/artifacts/predictions.npz`，但保留了 ARGUS 事件表、样本外切分和模型配置。
风险报告按当前规格复现样本外 Top4：

1. 使用现有 ARGUS 特征、切分日期、分类模型和种子生成测试期分数。
2. 每个 D0 只固定分数最高的四只股票；D+1 不可买时槽位现金，不向第五名补位。
3. 只为实际固定名单补齐 D+1 至报告截止日的 Tushare 日线、复权因子和 `stk_limit`
   数据，并缓存于被 Git 忽略的 `data/` 下。
4. 调用 `helix/eval/backtest.py` 的同一退出解析器生成原始与修正收益，避免报告脚本
   复制成交规则。
5. 三个既有随机种子分别计算指标，再报告均值、标准差和逐种子明细。

最终报告写入 `docs/risk/d2_limit_down_bias.md`，包含数据区间、样本数、成交规则、指标
定义、两组结果、偏差、异常样本统计、末端未平仓列表和可复现命令。

## 测试设计

测试按 TDD 顺序先写并观察失败，再写实现：

1. 连续三日全天封死跌停，第四日开盘开板：验证逐日扫描、开盘价成交、递延天数、
   持仓天数和收益率。
2. 某日开盘跌停、盘中开板、收盘回封：验证该日不成交并继续递延。
3. D+2 停牌：验证 D+1 已建仓不被 `LabelSet.valid=false` 抹掉，下一可交易日按顺序
   尝试开盘和收盘。
4. 回测末端仍封死或停牌：验证不虚构成交价、逐笔标为未平仓、两组日收益都保留
   现金槽位且 summary 单独计数。
5. 同日不同股票使用不同实际跌停价：验证不使用固定板幅推断。
6. 关闭开关：以现有测试夹具逐列比较回测日表和 summary，确保默认结果兼容。
7. 指标边界：覆盖零收益日对胜率和连续亏损的处理、盈亏比、CAGR 与样本对齐。

## 验收标准

- 所有新增边界测试完成红—绿循环。
- 全量 pytest 和 Ruff 检查通过。
- 默认关闭真实退出时，现有测试和基准结果不变。
- 风险报告由实际历史持仓和真实逐日行情生成，不含未来信息驱动的选股或补位。
- 报告至少给出 CAGR、最大回撤、日胜率、盈亏比、最大连续亏损、夏普比率、跌停
  样本占比、平均递延天数和平均亏损幅度，并单列停牌递延与末端未平仓。
